# Code of Conduct

This project follows the HAMi community
[Code of Conduct](https://github.com/Project-HAMi/community/blob/main/CODE-OF-CONDUCT.md),
which adopts the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Report unacceptable behavior to the HAMi maintainers listed in
[SECURITY-INSIGHTS.yml](SECURITY-INSIGHTS.yml), or to the CNCF as described in
the CNCF Code of Conduct.
